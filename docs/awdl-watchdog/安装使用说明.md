# Awdl Watch Dog· 安装与使用说明

## 一、问题描述以及是否需要安装Awdl Watch Dog

### 为什么会出现这个问题：

隔空投送「发现设备」靠蓝牙 BLE 广播。睡眠时 USB 控制器断电，蓝牙控制器会重新枚举一次。醒来后：

- 固件能重新灌进去（kext 那层会把命令发下去）；
- 但上层真正负责广播的那个进程（`bluetoothd`）**不会跟着重新初始化**，醒来后一条 LE 配置命令都不发。

结果就是蓝牙看着是开的，实际没在广播。这一层在用户态，无法通过Kext层实现

### 解决问题的办法：

睡眠唤醒后手动开关一次蓝牙或使用Awdl Watch Dog工具，他会在每次唤醒后8秒内自动帮你完成这个操作

## 二.安装教程

### 安装

在Releases里下载Awdl Watch Dog.zip

解压缩

右键解压缩出来的文件夹-服务-新建位于文件夹位置的终端窗口

```bash
sudo bash install-wakehook.sh
```

装完就完事，重启也还在。

## 卸载

```bash
sudo bash install-wakehook.sh uninstall
```

## 怎么确认它在工作

```bash
tail -20 /var/log/wakehook.log
```

#### 常见问题

**Q：会跟蓝牙 kext 冲突吗？**
不会。kext 只处理固件和命令补丁，看门狗只杀用户态进程，两者不碰同一个东西。

**Q：睡眠很久会不会重复杀？**
不会。只在完整唤醒那一刻触发一次，暗唤醒（后台维护）不触发。
